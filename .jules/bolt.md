## 2025-02-12 - Bulk get_post_meta array return optimization
**Learning:** `update_meta_cache` returns an array structured as `$meta_cache[$post_id][$meta_key][0]`. Using this returned array to replace `get_post_meta` calls inside loops eliminates function call overhead and significantly improves performance without compromising the WP object cache mechanism.
**Action:** When optimizing N+1 calls to `get_post_meta` inside a loop where `update_meta_cache` is already executed, store its return value and access the meta array directly instead of calling `get_post_meta`, remembering to add a fallback in case the key isn't set.
